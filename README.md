# Stack & Smoke theme

Shopify theme for **stackandsmoke.com**: BBQ and smoker gear, gift-ready kits for the grill guy. Stack it. Smoke it.

Built on Shopify's Dawn theme (MIT, see LICENSE.md), with:

- Charcoal and ember-orange color schemes, Oswald headings
- Slide-out cart drawer
- Homepage: hero, Why Stack & Smoke, The Stacks, "Stop opening the lid" thermometer feature, stocking stuffers under $30, tagline band, email signup
- Announcement bar linking to Gifts for the Grill Guy

Connected to Shopify through Online Store → Themes → Connect from GitHub (branch `main`). Edits in the Shopify theme editor commit back here, and pushes here sync to Shopify.
